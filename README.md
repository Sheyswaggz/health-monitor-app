# Health Monitor App

A modern health monitoring application with an Express.js backend and React frontend, containerized with Docker and deployed with Kubernetes.

## Project Overview

Health Monitor App is a full-stack application designed to track and monitor health metrics. Built with a focus on scalability, maintainability, and developer experience, it provides a robust foundation for health data management.

## Features

- **Real-time Health Monitoring**: Track and visualize health metrics
- **RESTful API**: Express.js backend with comprehensive endpoints
- **Modern Frontend**: React-based UI built with Vite
- **Data Persistence**: SQLite database for reliable data storage
- **Containerization**: Docker support for consistent environments
- **Orchestration Ready**: Kubernetes configurations for production deployment
- **CI/CD Pipeline**: Automated testing and deployment with GitHub Actions
- **Code Quality**: ESLint and Prettier for consistent code standards

## Tech Stack

- **Backend**: Express.js (Node.js 20+)
- **Frontend**: React with Vite
- **Database**: SQLite3
- **Containerization**: Docker & Docker Compose
- **Orchestration**: Kubernetes
- **CI/CD**: GitHub Actions
- **Code Quality**: ESLint (Flat Config), Prettier
- **Testing**: Jest

## Prerequisites

Before you begin, ensure you have the following installed:

- **Node.js**: Version 20.0.0 or higher
- **Docker**: Latest stable version
- **Docker Compose**: Latest stable version
- **Git**: For version control
